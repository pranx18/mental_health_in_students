🧠 Mental Health Data Analysis — EDA & Insights

This project explores patterns, trends, and correlations within a mental-health-related dataset using Python, Pandas, and visualization libraries. The goal is to understand key factors that influence mental well-being and uncover meaningful insights through Exploratory Data Analysis (EDA).

📘 Project Overview

The notebook (mental-health-pranathi.ipynb) includes:

Data cleaning

Handling missing values

Encoding categorical features

Visualizing mental health trends

Understanding relationships between variables

Identifying important patterns through charts

This project focuses on presenting the data clearly and extracting actionable mental-health insights.

📊 Key Analyses

✔ Distribution of mental health conditions
✔ Correlation heatmap between stress, mood, anxiety, etc.
✔ Demographic trends (age, gender, occupation)
✔ Lifestyle factors affecting mental health
✔ Visualization of rating scales
✔ Comparison of mental health metrics across groups
